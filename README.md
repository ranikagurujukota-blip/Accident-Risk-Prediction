# 🚦 Traffic Accident Prediction Using Machine Learning

## 📌 Project Overview

Traffic accidents are a major concern worldwide, causing injuries, loss of life, and property damage. This project aims to predict the likelihood of traffic accidents using Machine Learning by analyzing various factors such as weather conditions, road conditions, vehicle type, driver information, and environmental factors.

The application provides a user-friendly web interface where users can enter accident-related information and receive a prediction about the accident risk. The project demonstrates the practical application of Machine Learning in improving road safety and assisting in accident prevention.

---

## 🎯 Objectives

- Predict the probability of traffic accidents using Machine Learning.
- Analyze accident-related factors to identify potential risks.
- Build an interactive web application for easy predictions.
- Demonstrate the integration of Machine Learning with Flask.
- Improve awareness of accident risk based on input conditions.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/ranikagurujukota-blip/Accident-Risk-Prediction.git
```

### 2. Navigate to the Project Folder

```bash
cd Accident-Risk-Prediction
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Browser

```
http://127.0.0.1:5000
```
